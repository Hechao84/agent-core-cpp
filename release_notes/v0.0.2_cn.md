# 版本 v0.0.2

## 概述

v0.0.2 相比 v0.0.1 是一次较大的演进：

- `jiuwen-lite` 从偏单 Agent 演示形态，升级为具备多会话运行时、传输层解耦、原生 function calling、JSON 上下文持久化、运行时 MCP 管理、配置热重载能力的 C++ Agent 框架。
- `jiuwenClaw` 参考应用也扩展为包含 CLI、HTTP REST/SSE、Web UI、飞书通道、Agent 配置管理、MCP server 管理等能力的完整示例应用。

## 重点更新

### 框架层面

- 新增 `SessionManager`，作为按会话隔离上下文、按会话串行锁和全局并发控制的主要运行时入口。
- 新增 OpenAI 兼容模型和 Anthropic 模型的原生 function calling 支持，并保留纯提示词工具调用回退模式。
- 将上下文持久化从 Markdown 文件调整为 JSON 文件，并支持工具调用元数据持久化。
- 新增基于交互历史和空闲会话检测的 Dream 记忆整合机制。
- 重构 MCP 模块，支持运行时配置加载、连接/断开、工具注册与 live agent 工具同步。
- 新增 Agent 配置持久化、JSON 序列化和可选配置 watcher，支持热重载 Agent 配置。
- 新增会话级 `todo_*` 和 `ask_user` 工具。

### jiuwenClaw 层面

- 新增 HTTP REST/SSE server 和内置 Web UI。
- 新增飞书/Lark WebSocket 通道与通道管理能力。
- 新增 Agent 配置、技能、MCP server 等管理 API。
- 新增应用层 MCP server 持久化和运行时同步能力。
- CLI 支持会话切换、配置查看和运行时重载。
- HTTP 与飞书适配器拆分为独立静态库 target，便于复用或替换。

## 框架变更

### 运行时与会话管理

v0.0.1 主要通过直接调用 `Agent::Invoke(query, callback)` 使用 Agent。

v0.0.2 引入 `SessionManager`，运行模型变为会话感知：

- 每个会话拥有独立的 `ContextEngine`。
- 同一会话内的调用串行执行，避免同一会话并发写上下文。
- 通过 `AgentConfig::maxConcurrentSessions` 控制全局并发会话数量。
- 定义默认聊天、心跳、定时任务等保留会话。
- 通过 `ChannelMessage` 和 session key 派生机制支持不同传输层的会话路由。
- 配置变化后，可通过 `ReloadAgent` 重建 live agent。

### Agent 与记忆

`Agent` 新增历史和 Dream 记忆组件：

- 新增 `HistoryStore`，用游标记录交互历史。
- 新增 `DreamProcessor`，用于长期记忆整合。
- 新增会话 active/idle 通知。
- 用自动记忆整合替代旧的直接记忆操作流程。
- 通过 `DreamConfig` 控制历史批次、迭代次数、工具结果长度、记忆文件大小等限制。

### 上下文引擎

上下文持久化有较大调整：

- `ContextConfig::StorageType::MARKDOWN_FILE` 替换为 `JSON_FILE`。
- JSON 存储支持持久化 role、content、tool calls、tool call ID 和 tool name。
- SQLite 存储同步支持更丰富的消息结构。
- 通用存储逻辑抽取到 `ContextStorageBase`。
- LLM 上下文构造支持更完整的工具调用与工具响应消息结构。

### 模型与工具调用

模型抽象从纯文本响应升级为结构化响应：

- 在 `include/model.h` 中新增 `ToolCall`、`ToolSchema`、`ModelResponse`。
- `Model::Format` 接收工具 schema。
- `Model::Invoke` 返回包含文本和工具调用的 `ModelResponse`。
- OpenAI 兼容流式响应支持增量组装 `tool_calls`。
- Anthropic 流式响应支持 `tool_use` 和 `tool_result` 消息格式。
- `ModelConfig::useNativeFunctionCalling` 可启用原生 provider 协议，或回退到纯提示词 ReAct。
- `ModelConfig::extraParams` 支持透传常见模型请求参数。
- 回退解析器支持 JSON 风格工具调用和经典 ReAct `Action` 语法。

### 工具系统

工具层新增结构化 schema 和会话级构造能力：

- `Tool::GetJsonSchema()` 可根据工具参数生成 JSON Schema。
- `ResourceManager::BuildToolSchemas()` 生成原生 function calling 所需 schema。
- `ResourceManager::RegisterSessionTool()` 可注册需要会话资源的工具。
- 新增会话级工具：
  - `todo_create`
  - `todo_complete`
  - `todo_insert`
  - `todo_remove`
  - `todo_list`
  - `ask_user`
- `web_search` 工具增强为支持多个后端尝试和更清晰的失败反馈。

### MCP

MCP 支持从简单注册路径重构为运行时管理模块：

- MCP 实现迁移到 `src/mcp/`。
- 新增 `MCPConnection` 和 `MCPConfigManager`。
- 在公共类型中新增 `McpServerConfig`。
- `ResourceManager` 新增加载、注册、注销、查询 MCP server 的运行时 API。
- MCP 工具单独记录，server 断开时可同步移除。
- MCP server 连接失败不会阻断框架其他部分启动。

### 配置与技能

- 新增 `AgentConfig` JSON 序列化/反序列化。
- 新增 `AgentConfigStore`，用于 `./data/agents.json` 持久化覆盖配置。
- 新增 `ConfigWatcher`，用于基于轮询的 reload 工作流。
- 新增公共技能类型 `include/skill.h`。
- `Agent` 暴露技能列表和技能详情 API。
- 配置 schema 按多 Agent 设计，当前通过 `SessionManager` 同时运行一个 live agent。

### 兼容性说明

- v0.0.2 中 ReAct 是实际实现的执行模式。
- `AgentWorkMode::PLAN_AND_EXECUTE` 和 `AgentWorkMode::WORKFLOW` 暂未实现，后续考虑支持。
- Markdown 上下文存储已替换为 JSON 文件存储。
- 直接实例化 `Agent` 的应用建议迁移到 `SessionManager` 运行模型。

## jiuwenClaw 变更

### 应用架构

`jiuwenClaw` 重构为一个单入口参考应用，可运行在以下模式：

- 仅 CLI 助手。
- CLI + HTTP server + 已配置通道。
- 仅 HTTP server + 通道的守护进程模式。
- 带可选配置 watcher 的 server 模式。

### HTTP REST、SSE 与 Web UI

新增 HTTP server 适配器和内置 Web UI，覆盖聊天、会话和运行时管理能力：

- 聊天与流式聊天 API。
- 会话 CRUD 与会话历史 API。
- Agent 配置 API。
- 通道管理 API。
- 技能列表/详情 API。
- MCP server 管理 API。
- `ask_user` 回答 API。
- SSE 事件区分流式 token、状态、工具调用、工具响应、用户澄清问题和完成事件。

### 飞书与通道管理

新增飞书/Lark 集成，并将通道抽象为可持久化、可运行时协调的应用层资源：

- 飞书 WebSocket bot 适配器。
- `./data/channels.json` 持久化通道定义。
- 运行时通道 apply/remove/reconcile 服务。
- 通过 Web UI 与 REST API 管理通道。

### MCP Server 管理

新增应用层 MCP 持久化与 UI/API 集成：

- 新增 `McpServerManager`。
- 使用 `./data/mcp_servers.json` 持久化 MCP server 定义。
- 支持创建、更新、删除、重载 MCP server API。
- MCP server 变化后自动同步工具到 live agent。
- 删除 MCP server 时从 Agent 配置中级联清理对应 server id。

### CLI 改进

CLI 新增运行时管理命令：

- `/session <id>`：切换会话。
- `/sessions`：列出会话。
- `/reload`：重载 agents 和 channels。
- `/reload agent [<id>]`：重载指定 Agent 配置。
- `/reload channels`：重载通道配置。
- `/config show [<id>]`：查看生效配置。

### 提示词与模型更新

- 新增 `MEMORY.md`，用于 Dream 记忆整合。
- 提示词渲染支持注入长期记忆与当前会话 todo 状态。
- OpenAI 兼容模型支持通过 `extraParams` 注入厂商扩展参数。

### 构建与打包

- 将 HTTP 与飞书适配器拆分为独立静态库 target。
- 构建 `jiuwenClaw` 后复制 Web UI 文件。
- 更新 Linux 和 Windows 构建脚本与打包输出。
- 新增/更新配置、上下文相关单元测试，以及模型格式化和会话工具 smoke tests。

## 升级说明

- 将 `Agent::Invoke(query, callback)` 调用迁移到 `GetSessionManager().Invoke(sessionId, query, callback)`。
- 将 `ContextConfig::StorageType::MARKDOWN_FILE` 替换为 `JSON_FILE`。
- 如果关闭原生 function calling，需要检查工具提示词；回退模式期望 JSON 工具调用或经典 ReAct `Action` / `Action Input` 语法。
- 如果需要通过 Web UI/API 管理配置，请将运行时覆盖配置放入 `./data/agents.json`。
- 如果需要运行时管理 MCP，请将 MCP 定义放入 `./data/mcp_servers.json`。
