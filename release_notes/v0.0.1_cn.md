# 版本 v0.0.1

## 概述

`jiuwen-lite` 是一个轻量级、模块化的 C++ AI 代理框架，提供共享库以支持多种大型语言模型（LLM）提供商、代理工作模式、内置工具、模型上下文协议（MCP）集成和技能系统。

随框架发布的 `jiuwenClaw` 示例应用展示了如何使用这些核心能力来构建一个 AI 代理。

`jiuwen-lite` 框架的主要能力包括：

### 代理工作模式

框架提供三种内置的代理工作模式，以适应不同的推理和行动策略：

* **ReAct**：支持迭代推理和行动循环，使代理能够通过思考和观察逐步解决问题。
* **Plan-and-Execute**：允许代理先生成详细的行动计划，然后按顺序执行每个步骤。这种模式适用于需要结构化任务分解的场景。
* **Workflow**：未来计划支持基于节点的工作流执行，以编排更复杂的任务流程。

### LLM 支持

`jiuwen-lite` 框架支持两种 LLM API 格式：

* **OpenAI 兼容 API 格式**：支持与符合 OpenAI API 规范的 LLM 服务集成。
* **Anthropic API 格式**：支持与 Anthropic 提供的 LLM 服务交互。

### 内置工具

框架提供了一套基础的内置工具，代理可以使用这些工具与外部环境交互并执行各种操作。

| 工具名称 | 功能描述 |
| :-------------- | :--------------------------------------- |
| `time_info` | 获取当前时间或日期。 |
| `web_search` | 执行网络搜索。 |
| `web_fetcher` | 获取网页内容。 |
| `read_file` | 读取文件内容。 |
| `write_file` | 写入文件内容。 |
| `edit_file` | 原地编辑文件。 |
| `list_dir` | 列出目录内容。 |
| `glob` | 匹配文件模式。 |
| `grep` | 在文件中搜索内容。 |
| `exec` | 执行 Shell 命令。 |
| `skill_search` | 搜索并加载技能指令。 |
| `file_state` | 跟踪文件状态变化。 |

### MCP 集成

`jiuwen-lite` 框架通过支持模型上下文协议（MCP）与外部系统集成：

* 支持 STDIO、SSE 和 Streamable HTTP 传输，确保高效的数据交换。
* 可以连接到外部 MCP 服务器以扩展工具能力并集成更多服务。

### 上下文引擎

框架的上下文引擎管理代理的内存和状态，提供各种存储后端和高级功能：

* **存储后端**：支持临时数据的纯内存存储、消息持久化的 Markdown 文件，以及基于 SQLite 数据库的持久化存储。
* **高级功能**：包括自动 Token 估算和上下文窗口管理，有助于优化 LLM 的使用效率和成本。

### 技能系统

框架的技能系统允许代理动态加载和利用外部技能，增强其解决问题的能力：

* 支持从目录结构加载技能。
* 实现渐进式披露，元数据始终可用，完整指令按需加载。

## 示例能力 (`jiuwenClaw`)

`jiuwenClaw` 是 `jiuwen-lite` 框架的应用示例，其主要示例能力包括：

### 示例专属工具

`jiuwenClaw` 引入了一些示例特有的工具，以满足其应用场景的需求：

| 工具名称 | 功能描述 |
| :---------------- | :--------------------------------------- |
| `cron` | 安排、列出和删除提醒。 |
| `notify` | 跨平台桌面通知。 |
| `notebook_edit` | 编辑 Jupyter 笔记本。 |

### 核心组件

`jiuwenClaw` 示例应用包括以下核心组件，用于实现其特定的功能逻辑：

* **`HeartbeatManager`**：负责定期执行心跳任务，确保代理的持续运行和定期维护。
* **`CronWatcher`**：一个独立的定时任务模块，支持解析复杂的 cron 表达式并触发任务逻辑，不依赖于心跳周期。

### 提示词模板

`jiuwenClaw` 采用模块化的提示词管理策略，通过不同的 Markdown 文件定义代理的各个方面，实现灵活的行为控制。

* `AGENTS.md`：定义代理的行为指令。
* `SOUL.md`：描述代理的个性和价值观。
* `USER.md`：构建用户画像和偏好。
* `TOOLS.md`：指定工具使用策略。
* `REACT_SYSTEM.md`：组装系统提示词模板。

### 高级功能

* **记忆管理**：实现睡眠期间的自动记忆整理和长期记忆持久化，增强代理的记忆能力。
