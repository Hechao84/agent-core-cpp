## Overview

`jiuwen-lite` is a lightweight, modular C++ AI agent framework that provides a shared library to support multiple large language model (LLM) providers, agent working modes, built-in tools, model context protocol (MCP) integration, and skill management.

The `jiuwenClaw` sample application released with the framework demonstrates how to use these core capabilities to build an AI agent.

The main capabilities of the `jiuwen-lite` framework include:

### Agent Working Modes

The framework provides three built-in agent working modes to adapt to different inference and action strategies:

* **ReAct**: Supports iterative inference and action cycles, enabling agents to solve problems step by step through thinking and observation.
* **Plan-and-Execute**: Allows agents to first generate a detailed action plan and then execute each step in sequence. This mode is suitable for scenarios that require structured task decomposition.
* **Workflow**: Future plans include support for node-based workflow execution to orchestrate more complex task flows.

### LLM Support

The `jiuwen-lite` framework supports two LLM API formats:

* **OpenAI-compatible API format**: Supports integration with LLM services that comply with the OpenAI API specifications.
* **Anthropic API format**: Supports interaction with LLM services provided by Anthropic.

### Built-in Tools

A set of basic built-in tools is provided, which agents can use to interact with the external environment and perform various operations.

| Tool Name | Function Description |
| :-------------- | :--------------------------------------- |
| `time_info` | Obtain the current time or date. |
| `web_search` | Perform a web search. |
| `web_fetcher` | Fetch web page content. |
| `read_file` | Read file content. |
| `write_file` | Write file content. |
| `edit_file` | Edit a file in place. |
| `list_dir` | List the contents of a directory. |
| `glob` | Match file patterns. |
| `grep` | Search for content in a file. |
| `exec` | Execute shell commands. |
| `skill_search` | Search for and load skill commands. |
| `file_state` | Tracks file state changes. |

### MCP Integration

The `jiuwen-lite` framework integrates with external systems by supporting the Model Context Protocol (MCP):

* Supports STDIO, SSE, and Streamable HTTP transmissions, ensuring efficient data exchange.
* Can connect to external MCP servers to extend tool capabilities and integrate more services.

### Context Engine

The context engine of the framework manages the memory and state of the Agent, providing various storage backends and advanced features:

* **Storage backends**: Supports memory-only storage for temporary data, Markdown files for persistent messages, and SQLite-based databases for persistent storage.
* **Advanced features**: Includes automatic token estimation and context window management, which help optimize the efficiency and cost of using LLMs.

### Skill System

The skill system of the framework allows the Agent to dynamically load and utilize external skills, enhancing its problem-solving capabilities:

* Supports loading skills from a directory structure.
* Implements progressive disclosure, with metadata always available and full instructions loaded on demand.

## Example Capability (`jiuwenClaw`)

`jiuwenClaw` is an application example of the `jiuwen-lite` framework. Its main example capabilities include:

### Example-specific Tools

`jiuwenClaw` introduces some tools specific to the example to meet the needs of its application scenario:

| Tool Name | Function Description |
| :---------------- | :--------------------------------------- |
| `cron` | Schedules, lists, and deletes reminders. |
| `notify` | Cross-platform desktop notifications. |
| `notebook_edit` | Edits Jupyter notebooks. |

### Core Components

The `jiuwenClaw` example application includes the following core components to implement its specific functional logic:

* **`HeartbeatManager`**: Responsible for periodically executing heartbeat tasks to ensure the continuous operation and periodic maintenance of the Agent.
* **`CronWatcher`**: A standalone scheduled task module that supports parsing complex cron expressions and triggering task logic, without relying on the heartbeat period.

### Prompt Templates

`jiuwenClaw` employs a modular prompt management strategy, defining various aspects of the Agent through different Markdown files to achieve flexible behavior control.

* `AGENTS.md`: Defines the behavior instructions of the Agent.
* `SOUL.md`: Describes the personality and values of the Agent.
* `USER.md`: Constructs user profiles and preferences.
* `TOOLS.md`: Specifies the tool usage policies.
* `REACT_SYSTEM.md`: Assembles the system prompt templates.

### Advanced Features

* **Memory Management**: Implements automatic memory organization during sleep and long-term memory persistence, enhancing the Agent's memory capabilities.
